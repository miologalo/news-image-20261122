## How it works

`main.py` (Python 3.13, standard library only) validates the bundled
`entry.png` — JPEG magic and end marker, at most 1 MiB, at most 1024×1024 —
and copies it byte-identical to `/output/entry.png`. Both runs write the
same bytes (sha256
`feea789d2081bca14bae87b8129c73bc40b645258c49dac79432b56c54d2bb76`).
